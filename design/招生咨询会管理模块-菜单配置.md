# 招生咨询会管理模块 - 菜单配置指南

## 📋 菜单配置说明

由于我们已经创建了代码，但还需要通过系统的**菜单管理**功能来添加菜单项才能在左侧菜单中看到。

### 🚀 方法一：通过前端界面添加菜单（推荐）

#### 步骤：

1. **登录系统**
   - 访问：http://localhost:5180/web
   - 账号：admin / 密码：123456

2. **进入菜单管理**
   - 左侧菜单 → 系统管理 → 菜单管理

3. **添加一级菜单 - 招生咨询会管理**

   | 字段 | 值 |
   |------|-----|
   | 菜单名称 | 招生咨询会管理 |
   | 菜单类型 | 目录 |
   | 图标 | document（或其他合适的图标） |
   | 排序 | 3（或其他合适的数值） |
   | 权限标识 | （留空） |
   | 路由名称 | Consultation |
   | 路由路径 | /consultation |
   | 组件路径 | （留空） |
   | 状态 | 启用 |
   | 缓存 | 是 |
   | 显示 | 是 |
   | 标题 | 招生咨询会管理 |

4. **添加二级菜单 - 咨询会信息管理**（在"招生咨询会管理"下添加子菜单）

   | 字段 | 值 |
   |------|-----|
   | 菜单名称 | 咨询会信息 |
   | 菜单类型 | 菜单 |
   | 图标 | table |
   | 排序 | 1 |
   | 权限标识 | module_consultation:info_collection:query |
   | 路由名称 | ConsultationInfo |
   | 路由路径 | /consultation/info |
   | 组件路径 | module_consultation/consultation/index |
   | 状态 | 启用 |
   | 缓存 | 是 |
   | 显示 | 是 |
   | 标题 | 咨询会信息 |

5. **添加三级菜单 - 按钮权限**（在"咨询会信息"下添加子菜单，类型为"按钮"）

   | 菜单名称 | 权限标识 |
   |----------|----------|
   | 查询 | module_consultation:info_collection:query |
   | 新增 | module_consultation:info_collection:create |
   | 编辑 | module_consultation:info_collection:update |
   | 删除 | module_consultation:info_collection:delete |
   | 审核 | module_consultation:info_collection:approve |
   | 归档 | module_consultation:info_collection:archive |

└── 合规诊断 (菜单 - 待开发)

## 🔐 角色权限配置

1. **进入角色管理**
   - 左侧菜单 → 系统管理 → 角色管理

2. **为角色分配权限**
   - 点击"编辑"或"分配权限"
   - 勾选"招生咨询会管理"相关权限
   - 保存

3. **刷新页面**
   - 刷新浏览器页面后即可看到新菜单
