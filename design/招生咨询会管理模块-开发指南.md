## 🚀 快速开始

### 1. 执行SQL建表

在MySQL数据库中执行：
```bash
mysql -u root -p high_school_college < backend/sql/module_consultation.sql
```

或使用数据库管理工具导入 `backend/sql/module_consultation.sql`

### 2. 数据库表说明

| 表名 | 说明 |
|------|------|
| consultation_info | 咨询会信息表（核心表） |
| consultation_registration | 咨询会报名记录表 |
| consultation_itinerary | 咨询会行程表 |
| consultation_favorite | 咨询会收藏表 |
| consultation_comparison | 咨询会对比表 |

## 📝 开发模板

### 子模块标准结构

```
sub_module/
├── __init__.py
├── model.py        # 数据模型
├── schema.py       # 数据验证
├── crud.py         # 数据访问
├── service.py      # 业务逻辑
└── controller.py   # 控制器
```

## 🔧 配置检查

确保 `.env.dev` 配置正确：

```env
DATABASE_TYPE = "mysql"
DATABASE_HOST = "localhost"
DATABASE_PORT = 3306
DATABASE_USER = "root"
DATABASE_PASSWORD = "123456"
DATABASE_NAME = "high_school_college"

REDIS_ENABLE = True
REDIS_HOST = "localhost"
REDIS_PORT = 6379
```
