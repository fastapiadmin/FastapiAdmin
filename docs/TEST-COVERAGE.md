## 3. 下一批测试批次

### 批次 A：系统管理 CRUD（优先级最高）

- 菜单：目录/菜单/按钮/外链四种类型的必填、父子关系、组件路径、删除有子节点；
- 字典：类型/数据唯一性、状态、批量删除；
- 公告：草稿/发布/归档状态流转、空内容、XSS；
- 工单：创建/回复/状态流转；
- 版本：发布/撤回/排序；
- 参数：只允许更新、键名约束。

### 批次 B：认证与权限

- 登录：账号、密码、验证码、锁定、错误次数；
- token：刷新、过期、并发刷新；
- 权限：普通角色可见菜单/接口、越权 403；
- 改密：旧密码错误、弱密码、改密后旧 token 失效。

### 批次 C：文件与存储

- 上传：0 字节、1 字节、边界大小、超大、非法扩展名、路径穿越；
- MinIO：多桶、覆盖、下载、删除、目录打包；
- 文件传输：创建/重试/取消/失败步骤。

### 批次 D：任务与运维

- cron/interval/date 三种触发器；
- 非法 cron、过去时间、并发实例、失败重试；
- SQL 控制台：只读/写开关、超时、200 行限制、敏感列脱敏；
- SSH：密码/密钥、错误凭据、批量部分失败。

### 批次 E：生成器与 AI

- 表名/列名/包名/模块名边界；
- 预览、生成、覆盖、路径安全；
- AI 对话、记忆、模型切换、超长输入。

### 已发现的边界行为

- 0 字节文件当前允许上传；如需禁止需产品明确。
- 对象存储绝对路径 `/etc/passwd` 会被规范化为桶内 key `etc/passwd.txt`；`..` 路径会被拒绝。
- 传输任务非法 task_type / 空 targets 返回 422；合法任务创建成功。
- SQL 控制台写语句未 `confirmed=true` 会被拒绝；多语句被拒绝；查询超过 200 行会截断；`password` 列会脱敏。
- 导入/导出发现并修复两个真实问题：空 Excel 返回 500；导出带时区 datetime 导致 500；模板中文性别无法导入。
- SSH 终端发现并修复：非阻塞通道 `recv` 的超时被误判为 EOF，导致会话打开后立即关闭。

## 5. 完成标准

一个模块只有同时满足以下条件才标记“已覆盖”：

1. 正常路径；
2. 等价类/边界值/非法输入；
3. 权限与越权；
4. 状态流转和重复提交；
5. 数据清理；
6. 至少一个 UI 写操作（涉及页面时）。
