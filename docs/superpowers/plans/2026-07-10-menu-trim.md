## Task 2: 种子 JSON 同步(全新安装一致)

**Files:**
- Modify: `backend/app/scripts/data/platform_menu.json`(9 棵子树 status→1)

**Interfaces:** 无跨任务依赖。

- [ ] **Step 1: 用脚本给 9 棵子树递归置 status=1**

在仓库根执行(纯 Python,精确匹配 route_path,整棵子树含后代置 1,保留其它字段与顺序):

```bash
cd /Users/renyc/code/CodataAdmin
python3 - <<'PY'
import json
p="backend/app/scripts/data/platform_menu.json"
data=json.load(open(p,encoding="utf-8"))
DISABLE_ROOTS={"/swagger","/generator","/example"}         # 整目录
DISABLE_MENUS={"tenant","package","order","invoice","workspace","ticket"}  # 具体菜单
def disable(n):
    n["status"]=1
    for ch in n.get("children",[]) or []:
        disable(ch)
n_changed=0
for top in data:
    if top.get("route_path") in DISABLE_ROOTS:
        disable(top); n_changed+=1
    for ch in top.get("children",[]) or []:
        if ch.get("route_path") in DISABLE_MENUS:
            disable(ch); n_changed+=1
json.dump(data,open(p,"w",encoding="utf-8"),ensure_ascii=False,indent=2)
print("已停用子树根数:",n_changed)  # 期望 9
PY
```
Expected: `已停用子树根数: 9`
